WordCraft

纯 Rust 写的开源文字处理器，界面照 Word 的 Ribbon 做，原生读写 .docx，也能打开 .doc、.odt、.rtf、.md。

它能替代什么

  • Microsoft Word

实测

WordCraft 是 ArtCraft 团队用纯 Rust 写的开源文字处理器，目标是复刻 Word 的操作习惯：Ribbon 选项卡、样式库、标尺、导航窗格都在原来的位置，Ctrl+B、F4、F7 这些快捷键也沿用。

它原生读写 .docx（OOXML），也能打开 97-2003 的 .doc，导入 .odt、.rtf、.html、.md、.tex、.txt，导出 PDF 时文字可选中、链接和书签保留。修订、批注、目录、脚注、APA/MLA/Chicago/IEEE 引用、邮件合并、表格公式这些 Word 的重活都有对应功能。

官方在 ROADMAP 里给的自评是：功能目录覆盖 97%，但按深度、文件保真度和稳定性加权，约 60% 可用于真实工作。图表和 SmartArt 往返会丢，分页精度和原生打印还没完成，这是它现在还不能完全替掉 Word 的地方。

值得装的地方

  • 原生读写 .docx，能打开 Word 97-2003 的 .doc
  • Ribbon、样式、修订、批注、目录、脚注、邮件合并都有
  • macOS / Windows / Linux / BSD / 网页都能跑
  • MIT 或 Apache-2.0，拼写和语法检查离线完成

它做不到的

  • alpha 阶段，官方自评约 60% 可用于真实工作
  • 图表和 SmartArt 往返会丢
  • 分页精度和原生打印还没完成
