CADCraft

纯 Rust 写的开源 2D/3D CAD，命令行、对象捕捉、图层、标注、填充、块和 DXF 都按 AutoCAD 的习惯来。

设计★ 7,261本周 ↑ 315Apache-2.0见仓库
本站结论画平面图、改 DXF、出 PDF 够用；早期开发阶段，DWG 只写到 R2000，没建模的实体会丢。

它能替代什么

  • SolidWorks / AutoCAD

实测

CADCraft 把 AutoCAD 的命令行工作流搬了过来：输入 L、点两个点、输入 @5<45，回车；对象捕捉、极轴、正交、直接距离输入、夹点、右键重复都和原来一样。

它原生读写 DXF（R12 到 2018，ASCII 和二进制），DWG 通过 acadrust 读写（R13 到 2018）。图层、标注样式、填充、块、布局和视口、PLOT 出 PDF 都有，参数化约束这些进阶功能也在补。

官方标的是 early development：CADCraft 没有建模的实体，保存时会直接丢掉；SHX 字体不读，中文要靠系统字体回退。适合画平面图、改 DXF、出简单图纸，不适合当唯一的生产工具。

值得装的地方

  • 命令行、对象捕捉、极轴、直接距离输入，习惯接近 AutoCAD
  • DXF R12–2018 读写，DWG R13–2018 可开可存
  • 布局、视口、PLOT 出 PDF，SVG/PNG 导出
  • macOS / Windows / Linux / FreeBSD / 网页都能跑

它做不到的

  • 官方标 early development，功能还在快速补
  • 没建模的实体保存时会直接丢掉
  • SHX 字体不读，中文依赖系统字体回退
