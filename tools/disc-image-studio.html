Disc Image Studio

把图片刻进 CD、DVD、蓝光盘面，让盘面本身显示出肉眼可见的图案。

系统★ 7,078长青工具GPL-3.0WindowsmacOSLinux
本站结论能把照片刻进盘面；只能黑白、要光驱、要空白盘，小众但真能用。

它能替代什么

  • Nero Burning ROM
  • Acoustica CD/DVD Label Maker

实测

它只做一件很具体的事：把一张图片转换成符合光盘物理层约束的数据，刻录后盘面出现肉眼可见的图案，相当于把已经停产的 LightScribe 式盘面刻图能力带回来。Windows 版是图形界面，下载 win-x64.exe 直接运行，发布包自带 .NET 运行时；最新版 v1.4.1 就在今天发布。

付费刻录套件里的盘面设计功能（Nero、Acoustica 这类）做的是打印纸质标签或封面，它直接把图案刻进盘面本身；可以导出 ISO、RAW 或 WAV+CUE，也能配合 ImgBurn 等刻录软件使用，还能把文件一起存进盘里。

边界也很实在：图案只能是黑白二阶，没有彩色；需要刻录光驱和空白盘，现在多数电脑根本没有光驱；macOS 和 Linux 目前只有实验性命令行版；即时刻录标明是实验功能，官方建议只用可报废的测试盘。适合收藏、送礼、做实体纪念盘的人，不适合只想批量刻数据盘的人。

值得装的地方

  • Windows 有图形界面，下载即用
  • 支持 CD、DVD 与单层蓝光
  • 可导出 ISO，也能直接刻录
  • 7,078 星，GPL-3.0 开源

它做不到的

  • 只能刻黑白图案，没有彩色
  • 要刻录光驱和空白盘
  • macOS 与 Linux 只有实验性命令行版
  • 即时刻录是实验功能，可能刻废盘
