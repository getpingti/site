Concat

纯 Rust 写的开源视频剪辑器，对标剪映专业版：自动字幕、TTS、抠像、关键帧、4K 导出，无水印、无账号、全本地。

实测

Concat 是冲着剪映专业版去的开源剪辑器：自动字幕、文字转语音、抠像、关键帧、特效、多轨、4K 导出这些“打开剪映真正会用的功能”它都有，而且没有水印、不用登录、不上传素材，全部在本机跑。

它用 Rust 写引擎、GPU 做合成，官方说 4K 时间线能流畅预览；字幕走本地 Whisper，语音和抠像模型在设置里下载一次，之后离线可用。除了桌面端，还有 Android 和 iOS，项目文件跨平台通用。

官方自己标的是 beta：能用，但还有边角问题；Windows 安装包目前没有签名，SmartScreen 会拦，需要点“更多信息 → 仍要运行”。适合想摆脱剪映会员和上传的人，不适合依赖海量模板和插件接单的团队。

值得装的地方

  • 无水印、无账号、无订阅，素材不上传
  • 本地 Whisper 自动字幕，支持语音克隆和声音清理
  • 多轨、关键帧、100+ 效果、4K60 导出
  • Windows / macOS / Linux / Android / iOS

它做不到的

  • beta 阶段，复杂工程可能崩
  • AI 模型首次使用要单独下载
  • 模板和插件生态远不如剪映
