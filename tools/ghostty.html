Ghostty

原生界面、GPU 加速的终端模拟器，macOS 与 Linux 上又快又稳。

系统★ 63,610长青工具MITmacOSLinux
本站结论日常终端能替 Warp 九成；要 AI 助手、要 Windows 版就别想了。

它能替代什么

  • Warp

实测

MIT 开源的终端模拟器，目前 63,610 星，最新稳定版 1.4.0。macOS 版用 Swift 与 AppKit 编写，Linux 版用 GTK4，作者的目标是快、功能全、原生界面三者兼得，README 称已有数百万人每天使用。

日常终端工作里，Warp 免费版能做的它基本都有：原生标签页与分屏、主题跟随系统明暗、Kitty 图形协议、超链接，macOS 上还有下拉终端。替不掉的是 Warp 收费的 AI 助手与命令建议，以及 Windows 版——Ghostty 目前只支持 macOS 与 Linux。

边界也很清楚：它就是个终端模拟器，不带 AI、不带云同步；进阶配置要手写一个配置文件，喜欢图形化设置的人会觉得麻烦。适合每天泡在终端里、又不想为 AI 功能付费的人。

值得装的地方

  • 原生界面，macOS 用 Swift、Linux 用 GTK4
  • GPU 渲染，启动和滚动都快
  • 标签页、分屏、下拉终端齐全
  • 63,610 星，1.4.0 稳定版

它做不到的

  • 没有 Windows 版
  • 没有 Warp 那种 AI 功能
  • 部分高级功能要手写配置文件
