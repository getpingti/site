Stirling PDF

开源的 PDF 工具箱，50+ 功能：合并、拆分、签名、涂黑、转换、OCR、压缩，可桌面、浏览器或自建服务器。

它能替代什么

  • Adobe Acrobat
  • 在线 PDF 工具

实测

Stirling PDF 是一个开源的 PDF 处理平台，官方列了 50 多个工具：合并、拆分、签名、涂黑、格式转换、OCR、压缩、加水印、旋转、提取图片等，日常 Acrobat 里要付费或要上传在线的操作，它基本都能本地做。

它有三种用法：桌面客户端、浏览器界面、或者用 Docker 自建服务器。自建的好处是文件完全不出内网，还能通过 REST API 接到自己的自动化流程里；界面支持 40 多种语言。

注意它是 open-core：核心开源，但 SSO、审计、企业部署等能力属于付费版。如果你只需要日常 PDF 处理，免费版够用；要做深度版式编辑或复杂表单，Acrobat 仍然更强。

值得装的地方

  • 50+ PDF 工具，覆盖合并、签名、涂黑、OCR、压缩
  • 桌面 / 浏览器 / 自建服务器，文件不用上传
  • 界面 40+ 语言，Docker 一条命令起服务
  • 提供 REST API，可接自动化流程

它做不到的

  • open-core，部分企业功能收费
  • 深度版式编辑不如 Acrobat
  • 自建要会 Docker 和基本运维
